# Original source-script activation: first native dispatch slice

This checkpoint intentionally moves from proof-only M1B3 work to an executable
ACTI OnActivate dispatch path. It is NOT a declaration that general world
Enable/Disable is now fully admitted.

- The original OnActivate event is prepared from the immutable Player script
  catalogue with entered-program provenance.
- No-reference-change events keep their normal synchronous commit.
- Reference-changing ACTI events reserve the existing resident resource lane
  and queue an immutable transaction under its exclusive owner.
- On a later focused frame, the explicit gameplay ticket authorizes Ready ->
  Execute -> settlement/finalization. Ready alone never auto-commits.
- The activation reports Pending rather than successful completion until the
  transaction settles. Pauses, cancellation, load prevention, rollback, save
  deferral and recovery keep their existing guards.
- Original Enable syntax is compiled, staged and transaction-tested alongside
  the existing Disable implementation.
- Dialogue, quest-stage and 4 Hz GameMode paths are NOT redirected yet.
- The existing authored/dependency admission remains deliberately narrow and
  may reject most real placements; no bypass is made to force a demonstration.
- Native Android build, original-ESM case selection, and physical Quest
  verification remain separate acceptance requirements before claiming an
  end-to-end playable successful resident mutation.
