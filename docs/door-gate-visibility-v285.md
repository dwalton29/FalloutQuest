# v285: door aiming, animated collision and helper visibility

Local swing-door prompts use resident catalog names and live Open/Close/lock state. They do not request teleport metadata. Teleport prompts consume scene-prepared metadata and the prepared FULL-name index; neither missing metadata nor a missing name index starts ESM I/O from a HUD query.

Scripted BHK animation retains live triangle slots. A reference-to-triangle index is rebuilt after structural collision publications, then reused for poses and dirty-reference Bullet publication. Pose updates refit only affected coherent shapes, placed-object bounds and old/new spatial memberships in both player and prop/interaction grids. Authored mesh/vertex weld topology remains valid across these rigid node transforms. Enable/disable or topology changes retain the structural rebuild path. Per-reference render-shape indices replace animation's full scene scans, and collision matrices are produced only for actual BHK target blocks. Original animation clips, timing and collision remain enabled.

Trigger-directory NIFs become nonvisual resident references: no mesh/texture upload, draw, instancing, occlusion or A-button hit target. Original REFRs remain in residency for OnLoad and script volume events. Cold loading now uses the same existing marker/effect filter as transitions and streaming. NIF visibility selection preserves hidden ancestor branches and an inactive NiSwitchNode, and accepts an intentionally empty result without resurrecting every shape. Nonvisual references also pass private resident preparation and upload admission.

Regression coverage checks that swing aiming never requests a teleport prompt; hidden-root and inactive/selected switch admission; hidden animated resource retention; and 40 moving BHK poses alongside 4,000 static meshes. Incremental triangle/object grid memberships and bounds are compared with a complete rebuild. Original Megaton gatehouse animation is exercised locally from the supplied NIF, without checking original assets into Git.

Headset timing and screenshot verification remain necessary. The Vault 101 helper has a matching original Triggers model assignment. The exact stretched Super Duper Mart draw was not identified without its original NIF or a draw-ID capture; no location/model blacklist or arbitrary triangle cutoff is introduced.
