# v286: streamed gate collision, creature rigs and persistent load doors

The v285 animation fallback appended cached BHK triangles when an animated reference was no longer in the physical window. A distant visual gate could therefore invalidate/rebuild the entire collision world repeatedly. The animation path now distinguishes admitted physical references from the asset cache. Out-of-window poses retain metadata without inserting triangles, changing physical revisions or invalidating static indexes.

Rolling collision publication also cleared door/script poses and installed bind-pose triangles. A settled animation might never sample again. Same-context rolling windows now reapply the latest live poses before returning from publication, including on re-entry after far-cache eviction. Teleports and scene/origin changes clear old poses. Resident mutation publication exchanges physical scope with its collision snapshot so rollback remains allocation-free.

The original Deputy Weld record resolves to the Protectron skeleton and body parts, is enabled with 75 HP in a fresh original state, and has valid visible geometry. The idle loader nevertheless requested the humanoid `locomotion/mtidle.kf`. The original Protectron idle resides beside `skeleton.nif`; its locomotion folder contains `mtforward.kf`. Without an idle clip the upload path created no skinning rig, and live arrival rejected the actor. Creature idle, turn, walk, run, step and talking paths now follow their original creature layout; the nested idle lookup remains as a compatibility fallback. Humanoid conversation IDLEs are not bound to creature skeletons. Zero-triangle actor assembly is explicitly rejected and diagnosed. Authored alive/disabled/save state remains authoritative.

Megaton's exterior load door 00003B24 belongs to Wasteland persistent CELL 00002DB4. The old anchor fallback only searched the player's current CELL. The existing off-thread XTEL index now also indexes source WRLDs. An immutable anchor cache combines those links with original DATA positions and live enable-parent evaluation, refreshed by scene/enable publication. This includes persistent doors independently of which exterior grid CELL the player occupies. Exterior ray misses no longer enter the legacy CELL fallback that can synchronously scan the ESM. It retains the existing generic anchor geometry and interaction occlusion, with no special Megaton padding or forced activation. Disabled drawable doors cannot hide an enabled candidate behind them.

A separate v285 regression affected intentionally nonvisual DOORs: the placeholder upload skipped XTEL metadata and interaction bounds. Such doors retain original BHK bounds and teleport metadata without uploading visible geometry. Bounded diagnostics identify nearby door candidates, missing hits and the precise reference/model/node occluding an interaction ray.

Regression coverage includes settled-pose retention during rolling publication, 100 distant updates without physical invalidation, cache eviction/re-entry, scene-change reset, reversible scope exchange, world-scoped door selection and live-enable filtering. Original-record integration checks that Megaton's persistent entrance belongs to the Wasteland index. Optional original-asset integration executes the production NPC skinning/render bridge with the Protectron skeleton, root idle and body model; proprietary files remain external to Git. Software tests do not establish Quest frame-time gains or the state of an existing device save.
