# FalloutQuest

Experimental standalone Quest port project targeting Fallout 3 game data.

## Current milestone: Q2 — cloud-built Quest APK

The first goal is deliberately tiny: build an ARM64 Android APK in GitHub Actions, sideload it to a Quest 3, and prove the development pipeline works before introducing OpenXR or Fallout 3 parsing.

## Roadmap

- [x] Repository created
- [ ] Cloud-built Android APK
- [ ] APK launches on Quest 3
- [ ] OpenXR session + stereo rendering
- [ ] 6DoF head tracking
- [ ] Read user-supplied Fallout 3 game data
- [ ] Load a Fallout 3 interior
- [ ] Render Fallout 3 scene data in VR

## Legal / asset policy

This repository must not contain Bethesda game assets, executables, ESM files, BSA archives, textures, meshes, sounds, or other copyrighted Fallout 3 data. Users will need to supply files from their own legitimate Fallout 3 installation.

This project is not affiliated with or endorsed by Bethesda Softworks or Meta.
